# smartSpinTurn

Умный поворот относительно центра оси колёс с обратной связью по энкодерам через ПИД-регулятор и фазой дорегулирования.

## Описание

Алгоритм вычисляет рассогласование между целевым положением энкодеров и их текущим значением, непрерывно подавая корректирующее воздействие через ПИД-регулятор. При приближении к целевому углу робот переходит в фазу **дорегулирования**, удерживая позицию до полной стабилизации.

## Сигнатура

```sig
chassis.smartSpinTurn(90, null, false)
```

## Параметры

* **deg** (`number`): угол поворота в градусах (положительный — вправо, отрицательный — влево).
* **params** (`params.LineFollow`, опционально): объект с параметрами скорости и коэффициентами ПИД (`v`, `Kp`, `Ki`, `Kd`, `Kf`). Если не передан, используются настройки по умолчанию.
* **debug** (`boolean`): включение вывода графиков и ошибок на дисплей блока EV3.

## Пример

```blocks
chassis.smartSpinTurn(90)
```
